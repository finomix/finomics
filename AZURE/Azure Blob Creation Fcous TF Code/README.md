# Azure Blob Creation for Focus & CUR - Terraform

## 📌 Overview

This Terraform module creates all required Azure resources to store CUR, Focus, or any analytics data in **ADLS Gen2** with proper RBAC and ACL permissions.

The module provisions:

- Resource Group
- ADLS Gen2 Storage Account (HNS Enabled)
- Private Container (Filesystem)
- RBAC Assignment → `Storage Blob Data Reader`
- Recursive ACLs on ADLS Gen2 (Best Practice)
- Outputs including storage connection string

## 📤 Outputs

| Output                  | Description                              | Sensitive |
|-------------------------|------------------------------------------|-----------|
| `storage_account_name`  | Name of the created Storage Account      | No        |
| `container_name`        | Name of the created Blob Container       | No        |
| `connection_string`     | Primary connection string for the account| Yes    |

> The `connection_string` is marked sensitive and will not appear in terminal output.  
> To retrieve it, run:
> ```bash
> terraform output -raw connection_string
> ```

## ⚠️ Notes

- The Storage Account is created with **HNS (Hierarchical Namespace) enabled**, making it an ADLS Gen2 account.
- Replication type is set to `RAGRS` (Read-Access Geo-Redundant Storage).
- The `focus` directory path is created inside the container with recursive ACLs applied for both `access` and `default` scopes.
- The Service Principal is granted `Storage Blob Data Reader` via RBAC in addition to ACL-level permissions — this is the recommended approach for ADLS Gen2.
- Ensure the account running Terraform has sufficient privileges to create resource groups, storage accounts, and assign roles.
